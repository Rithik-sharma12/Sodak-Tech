# Archived frontend — Vite SPA (AI Studio export)

This was the first frontend attempt: a tab-based Vite + React SPA with no URL
routing. Navigation used `activeTab` state in `AppContext`, so links could not
be shared and refresh lost your place.

**Do not use this for launch.** It is kept only as a layout reference.

The canonical frontend is `../frontend/` — TanStack Start with file-based routes,
built from the Stitch design via Lovable.
